OpenCV Simple Color Detection

A simple Python project that detects specific colors in real time using a webcam and OpenCV.

Overview

The program captures frames from a webcam, converts them from BGR to HSV, and uses color thresholding to isolate a selected color.

Technologies

- Python
- OpenCV
- NumPy

How to Run

1. Clone the repository:

   git clone https://github.com/Codee472/Opencv-SimpleColorDetection.git

2. Install the dependencies:

   pip install opencv-python numpy

3. Run the script:

   python main.py
